СБОРКА APK БЕЗ ANDROIDIDE (через GitHub Actions)

1. Создай аккаунт GitHub и войди в браузере.
2. Нажми New repository. Назови его arbuz-companion. Для простоты выбери Public или Private — как тебе удобнее — и нажми Create repository.
3. В репозитории нажми Add file -> Upload files.
4. Распакуй этот ZIP на телефоне и загрузи ВСЕ файлы и папки из распакованного проекта. Важно: вместе с ними должна загрузиться скрытая папка .github/workflows и файл build-apk.yml внутри неё. Если файловый менеджер скрывает .github, включи показ скрытых файлов или создай workflow вручную через сайт GitHub.
5. Нажми Commit changes.
6. Открой вкладку Actions. Выбери Build ARBuz APK и нажми Run workflow -> Run workflow.
7. Дождись зелёной галочки. Открой завершённый запуск и найди блок Artifacts внизу страницы.
8. Скачай ARBuz-CHEAT-debug-apk.zip, распакуй его. Внутри будет app-debug.apk.
9. Перед установкой проверь, что файл получен именно из твоего успешного запуска GitHub Actions.

ВАЖНО:
- Это способ собрать APK в облаке, AndroidIDE не нужен.
- Проект остаётся companion-приложением с демонстрационной панелью; он не вмешивается в игру и не обходит античит.
- Сервер проверки ключей пока не развёрнут, поэтому вход по ключу не заработает до настройки собственного HTTPS backend.
- GitHub Actions собирает APK, но не исправляет ошибки исходного проекта автоматически.
